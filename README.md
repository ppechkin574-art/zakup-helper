# Помощник по госзакупкам — видеонаблюдение

Ищет на zakup.gov.kz открытые лоты по видеонаблюдению, читает техспецификации,
смотрит, со скидкой в сколько процентов такие лоты выигрывали раньше, и считает рентабельность.

## Запуск

```
cd ~/dev/zakup-helper
python3 server.py          # → http://localhost:8765
```

Внешних библиотек нет: нужен только Python 3 и `pdftotext` (`brew install poppler`).
Для .doc/.docx используется встроенный в macOS `textutil`.
Данные хранятся в `data/zakup.db` (SQLite).

## Откуда данные

Открытый API Единой платформы закупок, без авторизации:

| Что | Адрес |
|---|---|
| Лоты (поиск) | `/api/core/api/public/lots/?q=…&offer_end_date__gte=…` |
| Файлы объявления (техспека, сметы) | `/public/announcements/{id}/general-files/` |
| Договоры по коду ЕНС ТРУ | `/public/contracts/?enstru_code=…&sign_date__gte=…` |
| Договор: план и цена победителя | `/public/contracts/{id}/` → `plan_sum_with_vat`, `contract_price_with_vat` |

Особенности API:
- поиск `q` **не учитывает падежи** («видеонаблюдения» даёт 19 тыс. лотов, «видеонаблюдение» — 144),
  поэтому перебираются все формы слов (`zakup/source.py → KEYWORDS`);
- фильтр по статусу ненадёжен, «открытость» определяем по `offer_end_date >= сейчас`;
- у лотов Самрук-Казыны (SKK) файлы через API не отдаются.

## Поставщик keeper.kz

Токен лежит в `.env` (`KEEPER_TOKEN=…`), в git не попадает.

- Каталог (`/api/elements/`, ~44 тыс. позиций, ~12 мин): раз в сутки.
- Остатки и цены (`/api/quantity-price/`): раз в час.
- Категории (`/api/categories/`, лимит **1 запрос в минуту**, отдаёт только прямых детей): раз в неделю,
  обходятся только нужные ветки (видеонаблюдение, СКС, кабель, носители, питание, домофония, СКУД, ОПС), около часа.
- Закупочная цена = `final_price` = уровень **Платина**. `price` = **Золото** (его же отдаёт `quantity-price`). Если платина «по запросу» (0) — берём золото с пометкой.
- Монтаж: по умолчанию 20 000 ₸ за камеру (Настройки), камеры считаются из позиций сметы, только для лотов с монтажом.

Подбор в карточке лота: модели из техспеки (`DS-7632NXI-K2`, `IPC-B140HA-LUFC/SL`) ищутся в каталоге
сначала точно, потом без последних суффиксов («похожая»). Если модели нет — дешёвые позиции в наличии
из категорий по типу (купольная, цилиндрическая, регистратор, диск…). Кнопка «+ в расчёт» добавляет позицию в смету лота.

## Автоподбор

Сам собирает черновой расчёт по каждому лоту: товар у поставщика → монтаж → прибыль при типичной скидке и без скидки.
Правила (утверждены владельцем) — **[docs/AUTOPICK.md](docs/AUTOPICK.md)**, в панели — кнопка «Как считается».
Ручная правка в карточке важнее автоподбора; «Вернуть автоподбор» её сбрасывает.

## Как считается

- **Цена заявки по умолчанию** = сумма лота × (1 − медианная скидка победителей по этому коду ЕНС ТРУ за 6 мес.;
  учитываются только конкурентные способы, без «из одного источника»).
- **С НДС (ОУР):** прибыль = (цена/1,16 − расходы без НДС) × (1 − КПН 20%).
- **Упрощёнка:** прибыль = цена − расходы − 4% с цены.
- **Мин. цена** — ниже которой рентабельность падает ниже целевой.
- **Деньги на старте** = закупка + обеспечение заявки (1%) + обеспечение договора (3%).

Ставки редактируются в «Настройках». Сверьте с бухгалтером.
