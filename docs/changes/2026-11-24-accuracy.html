Точность оценки: каждая строка ТЗ в смете

24.11.2026 · помощник по госзакупкам · localhost:8765 · правила — docs/ECONOMICS.md, раздел 2.4

Коротко

  • Каждая строка ТЗ теперь в смете. Подбор научился находить экранированный кабель (F/UTP), кабель с питанием (КВК) с сечением из ТЗ, разъёмы BNC и ближайший больший кабель-канал, если нужного размера нет.
  • Чего нет у поставщика — оранжевая строка «впишите цену». Пока цена не вписана, лот в «Посмотреть вручную» («N строк сметы без цены»), а в расчёте предупреждение «прибыль завышена».
  • Замены не хуже ТЗ. «Другие варианты» предлагают только товары не хуже исходного: Мп, каналы, ТБ, порты и PoE, cat6, экран, размер кабель-канала, вольты и амперы. На кнопке видно, по чему сравнивали.
  • Остаток на складе. Сначала берётся товар, которого хватает на всё количество из ТЗ.
  • Поиск «Найти» — по словам строки ТЗ: окончания, «ъ/ь» и порядок размеров не важны, редкие слова (BNC, размер) важнее частых.
  • Плашка «срок истекает» над списком: выгодные лоты, у которых до конца приёма меньше суток.

Как это выглядит

Подбор у поставщика: две строки, которых нет у поставщика, подсвечены — поле «₸ за ед.» и кнопка «Найти у поставщика».

Расчёт предупреждает: «Прибыль завышена: 2 строки сметы без цены».

Плашка «До конца приёма меньше суток: 2 выгодных лота». Нажата — в списке только они.
