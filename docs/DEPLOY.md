# Сайт на GitHub Pages

Адрес: https://ppechkin574-art.github.io/zakup-helper/ — открыт всем, без пароля (решение 24.11.2026).
На сайте видно всё: лоты, расчёты прибыли, закупочные цены keeper.kz.

## Как работает

GitHub не умеет запускать наш сервер, поэтому сайт — готовые файлы, которые пересобираются раз в час:

1. `.github/workflows/pages.yml` — каждый час (и после каждого изменения в `main`) GitHub на своём Mac:
   - ставит программы для чтения ТЗ (`poppler`, `tesseract` с русским и казахским);
   - берёт базу с прошлого запуска (кэш GitHub, хранится до 7 дней без запусков);
   - запускает проверки `tests/`, затем `build_static.py`.
2. `build_static.py` — обновляет каталог keeper.kz (раз в сутки; остатки и цены — каждый запуск), лоты, ТЗ, историю цен, автоподбор и сохраняет в `site/` всё, что страница брала у сервера: `data/lots.json`, `data/lot/<id>.json`, `data/match/<id>.json`, `data/similar/<артикул>.json`, каталог для поиска `data/catalog.json`.
3. GitHub Pages показывает `site/`.

Ключ keeper.kz — секрет репозитория `KEEPER_TOKEN` (Settings → Secrets and variables → Actions). В файлах сайта и в коде его нет.

## Чем сайт отличается от версии на Mac

| | На Mac (`python3 server.py`) | Сайт |
|---|---|---|
| Обновление лотов | раз в 30 минут и по кнопке | раз в час, сам |
| Ваши цены, расчёты, параметры | в базе, общие | **в браузере** того, кто ввёл: команда их не видит, в другом браузере их нет |
| Загрузить ТЗ (Самрук-Қазына, сканы) | есть | нет — только на Mac |
| «Другие варианты» | для любого товара | для товаров из смет и подбора |
| Поиск «Найти» | на сервере | в браузере, по каталогу (≈5 МБ, грузится при первом поиске) |

## Если что-то сломалось

- Запуски и ошибки: вкладка **Actions** в репозитории. Перезапуск — «Обновление сайта» → **Run workflow**.
- Первый запуск или запуск после 7 дней перерыва — долгий (до часа): каталог и ТЗ скачиваются заново.
