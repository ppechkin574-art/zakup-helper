# Сайт на GitHub Pages

Адрес: https://ppechkin574-art.github.io/zakup-helper/ — открыт всем, без пароля (решение 24.11.2026).
На сайте видно всё: лоты, расчёты прибыли, закупочные цены keeper.kz.

## Как работает

**Данные собирает Mac, GitHub только показывает сайт.** Госпортал zakup.gov.kz не отвечает серверам GitHub
(они в США; проверено 24–25.11.2026: оба запуска сборки на GitHub — «timed out», с Mac — ответ за 0,3 с).
Поэтому собирать данные на GitHub нельзя.

1. На Mac работает `python3 server.py`: каждые 30 минут ищет лоты, читает ТЗ, обновляет цены keeper.kz, считает.
2. После каждого обновления сервер вызывает `publish.py`:
   - `build_static.export()` сохраняет в `site/` всё, что страница берёт у сервера:
     `data/lots.json`, `data/lot/<id>.json`, `data/match/<id>.json`, `data/similar/<артикул>.json`,
     каталог для поиска `data/catalog.json`;
   - если лотов 0 — сайт **не** обновляется (чтобы не выложить пустой);
   - иначе `site/` отправляется в ветку `gh-pages` одним сохранением (старые затираются — репозиторий не растёт).
3. GitHub Pages показывает ветку `gh-pages` (Settings → Pages → Deploy from a branch → `gh-pages`).

**Mac выключен или сервер не запущен** — сайт работает, но показывает данные последнего обновления
(время — на кнопке вверху: «Обновлено …»).

Выложить вручную: `python3 publish.py`. Нужен вход в GitHub на этом Mac (`gh auth status`).

На GitHub остаётся только автопроверка правил при каждом изменении кода (`.github/workflows/tests.yml`).
Ключ keeper.kz на GitHub больше не нужен: секрет `KEEPER_TOKEN` можно удалить
(Settings → Secrets and variables → Actions).

## Чем сайт отличается от версии на Mac

| | На Mac (`python3 server.py`) | Сайт |
|---|---|---|
| Обновление лотов | раз в 30 минут и по кнопке | когда Mac обновил данные |
| Ваши цены, расчёты, параметры | в базе, общие | **в браузере** того, кто ввёл: команда их не видит, в другом браузере их нет |
| Загрузить ТЗ (Самрук-Қазына, сканы) | есть | нет — только на Mac |
| «Другие варианты» | для любого товара | для товаров из смет и подбора |
| Поиск «Найти» | на сервере | в браузере, по каталогу (≈5 МБ, грузится при первом поиске) |
